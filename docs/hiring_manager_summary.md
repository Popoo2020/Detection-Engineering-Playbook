# Hiring Manager Summary

## What this project demonstrates

Detection-Engineering-Playbook demonstrates practical security detection thinking: KQL examples, Sigma rule structure, ATT&CK mapping and validation workflow.

## Relevant roles

- SOC Analyst
- Detection Engineer
- Microsoft Sentinel / SIEM Analyst
- Security Monitoring Analyst
- Cybersecurity GRC roles involving detection-control evidence

## What this demonstrates

- Ability to document detection logic.
- Understanding of ATT&CK-style mapping.
- Sigma and KQL awareness.
- CI validation of rule structure.
- Awareness that detections require tuning and validation before production use.

## Current limitations

The repository currently validates structure rather than detection precision or recall. The next step is to add representative event fixtures, more ATT&CK coverage and detection-quality metrics.
